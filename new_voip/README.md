# new_voip - SIP/RTP клиент для телефонии

Простой SIP/RTP клиент на Python для совершения телефонных звонков с воспроизведением аудио файлов.

## Особенности

- Поддержка SIP протокола (REGISTER, INVITE, BYE, ACK)
- Поддержка RTP аудио (G.711 A-Law / PCMA)
- Дайджест-аутентификация
- Воспроизведение аудио файлов с зацикливанием
- Асинхронная реализация на asyncio

## Требования

```bash
pip install numpy
```

## Быстрый старт

### 1. Подготовка аудио файла

Аудио файл должен быть в формате:
- **Частота дискретизации**: 8000 Hz
- **Каналы**: 1 (моно)
- **Разрядность**: 16-bit PCM
- **Формат**: WAV

Если у вас файл в другом формате, используйте скрипт конвертации:

```bash
cd new_voip
python3 convert_audio.py "/путь/к/вашему/файлу.wav" "audio.wav"
```

Пример конвертации:
```bash
python3 convert_audio.py "/home/user/Test_Phone_new/2022-07-22 - Phaera Homebound.wav" "audio.wav"
```

### 2. Настройка параметров

Отредактируйте `main.py`:

```python
SIP_USER = "555533"          # Ваш SIP номер
SIP_PASS = "Test1234"       # Ваш SIP пароль
SIP_SERVER = "192.168.1.176" # IP адрес SIP сервера (Asterisk)
LOCAL_IP = "192.168.1.181"  # Ваш локальный IP адрес
TARGET_NUMBER = "1001"      # Номер для звонка
```

**ВАЖНО**: Убедитесь, что `LOCAL_IP` указан правильно - это критично для работы SIP/RTP!

### 3. Запуск

```bash
cd new_voip
python3 main.py
```

### 4. Управление

- Программа автоматически зарегистрируется на SIP сервере
- Позвонит на указанный номер
- Начнет воспроизводить аудио файл (зацикленно)
- Нажмите `Ctrl+C` для завершения звонка

## Конвертация аудио файлов

### Использование скрипта

```bash
python3 convert_audio.py <input_file> [output_file]
```

### Примеры

```bash
# Автоматическое определение имени выходного файла
python3 convert_audio.py "music.mp3.wav"

# Указание выходного файла
python3 convert_audio.py "music.mp3.wav" "audio.wav"

# Конвертация в другую частоту (по умолчанию 8000 Hz)
python3 convert_audio.py "input.wav" "output.wav"
```

### Поддерживаемые форматы

- Вход: WAV (любой формат, поддерживаемый wave)
- Выход: WAV (8000 Hz, Mono, 16-bit PCM)

## Проблемы и решения

### Звук искажен ("дрель в ушах")

**Причина**: Грубый ресемплинг в TTSSource при конвертации из 24000 Hz в 8000 Hz.

**Решение**: Используйте FilePlayerSource с предварительно конвертированным аудио файлом 8000 Hz.

### Не работает аутентификация

**Причина**: Неправильный URI или отсутствует `;transport=UDP`.

**Решение**: Исправлено в текущей версии. Убедитесь, что используете актуальный код.

### SIP сервер не отвечает

**Причины**:
1. Неверный `LOCAL_IP` - проверьте ваш IP адрес
2. Блокировка портов - откройте порты 5060 (SIP) и 10000-15000 (RTP)
3. Неверные учетные данные - проверьте логин/пароль

**Решение**:
```bash
# Проверить IP адрес
ip addr show

# Проверить открытые порты (Linux)
sudo netstat -tulpn | grep :5060
```

## Сравнение с pyVoIP

### Что упрощено в new_voip:

- Только UDP для SIP
- Только PCMA для аудио
- Упрощенная система аутентификации
- Упрощенный парсинг сообщений
- Без jitter buffer
- Без поддержки DTMF
- Без механизма retry

### Что реализовано в pyVoIP, но отсутствует в new_voip:

- Полноценный RTP клиент с jitter buffer
- Поддержка нескольких кодеков (PCMU, PCMA, telephone-event)
- Сложная система обработки SIP сообщений
- Механизм retry с экспоненциальным backoff
- Поддержка TCP и TLS для SIP
- Поддержка IPv6
- Полный парсинг SDP
- Обработка VIA заголовков с NAT traversal
