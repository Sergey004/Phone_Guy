  PcmMedia(clockRate=16000, channelCount=1, samplesPerFrame=160)
    Создание экземпляра с параметрами
    
  pcm.start()
    Начать обработку аудио
    
  pcm.stop()
    Остановить обработку

    Отправить PCM семплы (bytes, bytearray или array.array)

📝 ПРИМЕР

  from native import PcmMedia
  import array
  import math
  
  # Создание
  pcm = PcmMedia(clockRate=16000, channelCount=1, samplesPerFrame=160)
  
  # Генерация тестового сигнала (1000 Hz, 1 сек)
  samples = []
  for i in range(16000):
      s = int(32767 * math.sin(2 * math.pi * 1000 * i / 16000))
      samples.append(s)
  
  # Отправка
  audio = array.array('h', samples)
  pcm.push(audio)
