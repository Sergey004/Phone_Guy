# RVC Fix Documentation

## Проблема
Ошибка `NameError: name 'rvc_infer' is not defined` возникала потому, что приложение запускалось в системном Python (miniconda3), где не было установлен PyTorch и других зависимостей RVC.

## Решение

### 1. Исправлено в `new_voip/tts_adapter.py`
- Добавлена обработка ошибок при импорте `rvc_infer`
- Добавлено логирование успешного/неудачного импорта
- Добавлена проверка `rvc_infer is None` перед вызовом
- RVC автоматически отключается, если модуль недоступен

### 2. Исправлено в `new_voip/main_integration.py`
- Добавлены проверки зависимостей при запуске
- Проверяется наличие PyTorch
- Проверяется наличие RVC модуля
- При отсутствии зависимостей выводятся инструкции и приложение завершается

### 3. Создан скрипт `run.sh`
Удобный скрипт для запуска приложения с правильным виртуальным окружением.

## Как запустить приложение

### Вариант 1: Используя скрипт run.sh (Рекомендуется)
```bash
./run.sh
```

### Вариант 2: Вручную
```bash
source /home/user/Test_Phone_new/.venv/bin/activate
python new_voip/main_integration.py
```

## Важные моменты

1. **Всегда используйте виртуальное окружение `.venv`**
   - В системном Python (miniconda3) нет PyTorch и других зависимостей
   - Все зависимости установлены в `.venv`

2. **Проверки при запуске**
   - Приложение проверяет наличие PyTorch и RVC перед запуском
   - Если зависимости не найдены, вы увидите сообщение с инструкциями

3. **RVC работает корректно**
   - В `.venv` установлен PyTorch 2.6.0+cu124
   - RVC модуль успешно импортируется
   - Все необходимые зависимости доступны

## Файлы, которые были изменены

1. `new_voip/tts_adapter.py` - добавлена обработка ошибок импорта RVC
2. `new_voip/main_integration.py` - добавлены проверки зависимостей при запуске
3. `run.sh` - создан скрипт для удобного запуска

## Диагностика

Если у вас возникнут проблемы с RVC:

1. Проверьте, что используете правильное окружение:
   ```bash
   which python
   # Должно показывать: /home/user/Test_Phone_new/.venv/bin/python
   ```

2. Проверьте наличие PyTorch:
   ```bash
   python -c "import torch; print(torch.__version__)"
   # Должно показывать версию PyTorch
   ```

3. Проверьте импорт RVC:
   ```bash
   python -c "from rvc_py.rvc_infer import rvc_infer; print('OK')"
   # Должно показывать: OK
   ```

4. Запустите приложение:
   ```bash
   ./run.sh
